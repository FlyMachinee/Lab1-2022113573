# SE Lab1: 基于有向图的文本数据处理程序

以下内容均由 `Gemini 2.5 Flash` 生成

本项目是哈尔滨工业大学软件工程课程 Lab1 的成果，旨在实现一个程序，从文本文件中读取数据，构建一个带权有向图，并在此图上执行一系列计算和查询操作。项目采用 Python 语言，并使用 PySide6 构建图形用户界面 (GUI)，使用 Graphviz 进行图的可视化。

## 项目功能

本项目实现了实验手册中要求的所有核心功能，并包含部分可选功能：

1.  **读入文本并生成有向图**:
    * 从文本文件或直接输入的文本中读取英文文本数据。
    * 对文本进行清洗，处理换行符、标点符号和非字母字符，忽略大小写 。
    * 根据相邻单词出现的频率构建带权有向图 。
2.  **展示有向图**:
    * 在 GUI 界面中以文本格式展示图的邻接关系。
    * 可选功能：将生成的有向图可视化并以图像文件形式保存（使用 Graphviz）。
3.  **查询桥接词 (Bridge Words)**:
    * 输入两个单词 word1 和 word2，查询图中是否存在 word1 -> word3 -> word2 的路径，其中 word3 即为桥接词。
    * 能处理单词不存在或桥接词不存在的情况 。
    * 能列出所有桥接词或提示没有桥接词.
4.  **根据 Bridge Word 生成新文本**:
    * 输入一行新文本，遍历文本中的相邻单词对。
    * 如果相邻单词对之间存在桥接词，则随机选择一个桥接词插入它们之间。
    * 输出生成的新文本。
5.  **计算两个单词之间的最短路径**:
    * 输入两个单词，计算它们之间在图中的最短路径（基于边权值之和）。
    * 在 GUI 中显示最短路径的长度和路径上的节点序列。
    * 可选功能：计算从一个单词到所有其他可达单词的最短路径 。
    * 可选功能：可视化最短路径，在图的图像展示中标注出路径 。
    * 能处理两个单词不可达的情况 。
    * 可选功能：计算并展示所有最短路径（如果存在多条） 。
6.  **计算 PageRank**:
    * 实现 PageRank 算法计算图中每个节点（单词）的重要性。
    * 支持处理出度为 0 的节点（悬挂节点） 。
    * 支持不同的初始化策略（例如：均匀初始化、基于入度、基于入边权重总和），以及可选的基于关键词权重的初始化 。
    * 在 GUI 中以表格形式展示 PageRank 计算结果。
7.  **随机游走**:
    * 从图中随机选择一个节点作为起点，沿着出边进行随机遍历。
    * 记录并显示遍历经过的节点序列。
    * 游走在遇到重复的边或进入没有出边的节点时停止 。
    * 用户可以随时手动停止游走 。
    * 将遍历的节点序列输出为文本。

## 安装和运行

1.  **安装 Python:** 确保你的系统安装了 Python 3.6 或更高版本。
2.  **安装依赖库:** 打开终端或命令提示符，安装项目所需的 Python 库：
    ```bash
    pip install PySide6 graphviz
    ```
3.  **安装 Graphviz 软件:** Graphviz 是一个独立的图绘制软件，你的系统需要安装它，以便 Python 的 `graphviz` 库能够调用其命令行工具生成图片。访问 [Graphviz 官方网站](https://graphviz.org/download/) 下载并安装适合你操作系统的版本，并确保 Graphviz 的可执行文件路径已经添加到系统的 PATH 环境变量中。
4.  **克隆或下载项目:** 将本项目文件下载到你的本地。
5.  **运行程序:** 打开终端或命令提示符，进入项目根目录，运行 `MyWidget.py` 文件：
    ```bash
    python MyWidget.py
    ```
6.  程序将启动 GUI 界面，你可以通过界面上的控件进行各项操作。

## 使用说明

打开程序后，请按照以下步骤操作：

1.  **生成图:**
    * 在“生成图”选项卡中，选择“从文件生成”并指定你的文本文件路径 。
    * 点击相应的生成按钮，程序将根据输入的文本构建有向图。
2.  **查看图:**
    * 切换到“展示图”选项卡，可以选择“文本模式”查看图的邻接表表示 ，或选择“图片模式”可视化展示图。
    * 在图片模式下，你也可以选择将图保存为 PNG 图像文件。
3.  **其他功能:**
    * 切换到对应的选项卡（查询桥接词），根据界面提示输入必要的参数，点击按钮执行相应的计算或操作。结果将在界面上显示。
